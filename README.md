# smart-restaurant-ordering-system
 Python-based Restaurant Management System for handling orders, menu management, billing, discounts, sales reporting, table reservations, and inventory monitoring
A console-based restaurant management system developed in Python that allows customers to place orders and staff to manage menus, sales reports, discounts, inventory, and table reservations.

# 🍽️ Smart Restaurant Ordering System

A comprehensive Restaurant Management System developed in Python that helps restaurant staff and customers manage orders, menus, billing, discounts, inventory, sales reports, and table reservations through an easy-to-use console interface.

---

##  Overview

Managing a restaurant involves handling multiple daily operations such as receiving orders, calculating bills, managing menus, tracking sales, and monitoring inventory.

This project automates these tasks and provides an organized solution for both restaurant staff and customers.

---

##  Features

###  Customer Features
- View restaurant menu
- Search for menu items
- Place orders easily
- Validate saved orders
- Calculate total bill automatically
- Apply customer discounts
- View available tables
- View best-selling menu items

###  Agent Features
- Customer registration system
- Estimate order preparation time
- Add new menu items
- Remove existing menu items
- Low stock monitoring
- Export daily sales to CSV files
- Generate daily sales reports

##  Menu Management

The system loads menu items from text files and allows:

- Viewing available meals
- Searching for meals
- Adding new menu items
- Removing menu items
- Managing customer-suggested meals

---

##  Billing & Discounts

The system automatically:

- Calculates order totals
- Applies first-visit discounts
- Supports discount codes
- Generates order summaries

---

##  Reporting & Analytics

Restaurant staff can:

- View best-selling items
- Generate daily sales reports
- Track revenue
- Export sales data to CSV format

---

##  Table Reservation Support

The system provides:

- Regular tables
- VIP tables
- Available table tracking

---

##  Preparation Time Estimation

Each menu item has a predefined preparation time.

The system calculates the estimated preparation time for customer orders automatically.
